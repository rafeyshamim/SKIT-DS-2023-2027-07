AI-Powered 3D Medical Image Reconstruction & Disease Analysis

Frontend requirements and low-fidelity wireframes for the Streamlit application — covering the upload flow, 3D reconstruction viewer, and the AI prediction/report screen. This is the reference the rest of the frontend sprint (visualization component, results UI, report generation) will be built against.

Frontend requirements

  • Framework: Streamlit (Python), talking to the FastAPI backend over REST.
  • Screen 1 — Upload: accept a CT scan (DICOM/NIfTI series), show file/series info, trigger preprocessing + reconstruction.
  • Screen 2 — 3D Viewer: render the reconstructed 3D organ model, with basic rotate/zoom and a slice scrubber for the source CT.
  • Screen 3 — Results: show the AI disease prediction, a confidence score, and a "Download PDF report" action.
  • State: a simple linear flow (Upload → Processing → Viewer → Results); no login/auth needed for MVP.
  • Non-functional: clear loading/progress states during model inference (this can take time); plain-language error states if a scan fails to load.
